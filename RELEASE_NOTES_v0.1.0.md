# NEXIUM 0.1.0

The first public release of NEXIUM for Windows.

### Included

- Create and manage separate Minecraft instances.
- Install Minecraft versions and supported mod loaders.
- Browse the Modrinth catalog and install game content.
- Configure Java, memory, Minecraft language, and launcher behavior.
- Customize the launcher background and use Discord Rich Presence.

### Notes

- Some modpacks may require additional files to be installed manually. Follow the instructions provided by the modpack author.
